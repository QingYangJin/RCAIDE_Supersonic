# L-30 Addendum 01 — q 源裁定（ATM-F1R2）与任务表更正

- addendum_id: L-30-A01
- 日期: 2026-11-13
- 父决策: L-30（lead tree commit 27f8d91）
- 触发: A1 指出 L-30 表 M2.02 q 单元格与 L_ref/mass 不自洽；A1 建议改用 ISO-1 标准 ISA
- 裁定: **采用 ATM-F1R2（A1 冻结大气常数），不采用 ISO-1**

## 1. 理由

1. M2.02 / 18,288 m 是当前唯一有真实 F1R2/F2R2 执行先例的条件；必须与该已验证点逐常数连续，保留 F1R2 q=20,483.940233430174、Vinf=596.0373972278921、rho=0.1153178340089936、ReCref=89,397,005.8767656 作为任务族锚点。
2. 换 ISO 会使 M2.02 q 相对 F1R2 变 1.24e-5，损失锚点连续性；对 2.2/1.8 同样只带来 1.24e-5 差异，科学收益不足。
3. ATM-F1R2 是自洽的 18,288 m 大气模型（p=7171.544888256813、T=216.65、R=287.05287、rho=0.1153178340089936、a=295.06801842964956），2.2/1.8 由同一模型计算，不混用 ISO。
4. 披露: ATM-F1R2 与 ISO 标准 ISA 的 q 差 rel≈1.24e-5；M2.02 与 F1R2 完全连续；2.2/1.8 是新条件，不继承 F1R2 expected polar；M1-A 重新建立 admission baseline；不得宣称新任务 deck 与 F1R2 字节相同（除 M2.02 同参数 deck 外）。
