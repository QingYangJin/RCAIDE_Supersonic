## 1. F-QE-feasible-v2 校准与冻结协议

**1.1 版本化（不动旧 F-QE）**
- 新 family_id = `F-QE-feasible-v2`，作为 `task_family.py` 独立版本注册；旧 `F-QE` 公式、参数分布、fingerprint 逐位不变（回归测试锁旧 fingerprint 常量）。
- v2 公式沿用可解析二次族：`f(u)=b+Σ a_i(u_i-c_i)²`，`g(u)=Σ w_i(u_i-d_i)²-r_v2²≤0`，约束方向恒 `g≤0`；**v2 取 `d=c`**（参考解 = 中心点径向投影，中心恒可行 → `u*=c`、`f*=b_eff`、KKT 残差 = 0，参考断言 <1e-10）。
- **v2 是独立版本，不是旧 F-QE 的半径调参**：新 family_id / family_version（v2）、显式参考解几何（d=c）、半径分布按校准证据扩展，三者单独成立；v2 与旧 F-QE **不可逐位对照**（任务参数采样、task_id、可行几何、绝对目标均不同），只在同一套臂/预算/统计规则下各自独立报告。旧 F-QE 公式、参数分布、fingerprint 逐位不变，原样保留为压力测试（其 ~1e-6 可行域代表"极小可行域"极限，结论单表）。
- **CONTRACT_AMBIGUITY A13（已由 Lead 裁决，2026-11-04）**：上一版计划曾写"v2 与旧 F-QE 唯一差别=半径分布"，与 §1.1 显式公式 d=c 冲突。裁决=保留 d=c，修正措辞：v2 是独立版本（见上一条），不改回旧 F-QE 同几何。理由：参考解可解析认证（u*=c、f*=b_eff、KKT=0），M5 主终点 gap_to_reference 无需数值求参考解，可复算性最强；旧 F-QE 几何仅作为压力测试保留。
- 参考解断言（fail-closed，测试覆盖）：在 u*=c 处全部启用约束严格可行 `g_i(u*)<0`（margin>0）、objective 有限、KKT 残差=0；任一任务不满足即整批 FAIL，不构造正式任务。
- 参数分布（冻结）：`c_i~U(0.15,0.85)`、`a_i~LogU(0.5,5)`、`w_i~LogU(0.5,5)`、`b~U(-1,1)`、`r_v2=clip(radius_base·(1+0.15·z), r_min, r_max)`，`z~N(0,1)` 由 task seed 派生；context 与旧族同构（2 维，`[0.6,1.4]`）。
- 可行体积分数 p 用 12 维球体积近似 `V_12=π^6/6!≈1.335`：`p≈1.335·r_v2^12`（解析球近似；实际椭球还要除 `sqrt(prod w)≈15.7`，故同 p 需要更大半径——见 A12）。**pilot 实测**（4 个 meta_train 任务 × seed 0、B=64、BO-random、d=c）：r=0.75 → success 50%/hit 4.3%；r=0.85 → 75%/15.2%；r=0.95/1.05/1.15 → success 100%、hit 19.5%/26.2%/39.1%（原始记录 `probe_v2_radius.json`）。

**1.2 校准协议（只在 meta_train 上选半径；只用 meta_train / meta_validation 构造任务）**
- 校准 cohort：meta_train 8 任务 + meta_validation 8 任务（v2 配置，正式规模训练/验证任务子集），**不生成、不读取 meta_test/ood**；测试集 split 在冻结前只以 sealed hash 存在。
- 网格：`radius_base ∈ {0.55,0.60,0.65,0.70,0.75,0.80,0.85,0.90,0.95,1.00}`（依据 pilot 实测扩网格，见 §1.1 A12）；每格跑普通 BO（随机 8 初始 + B=64，即 `BO-random` 同引擎）各 3 个固定优化种子 **seeds=(0,1,2)**（seed 列表写入 plan 与 calibration_report；10 格 × 16 任务 × 3 seeds = 480 次 B=64 run，单机 pilot 量级）。
- **半径选择只用 meta_train 任务**（meta_validation 仅作难度旁证，不参与选中判定）：对每格按 seed 汇总 8 个训练任务的 **pooled success rate**（成功任务数 / 8，再跨 3 seeds 取 pooled），选 pooled success 落在 **[0.30, 0.70]** 的格（安全落在 20–80% 验收带内）；多格命中时取 pooled `feasible_hit_rate` 中位数最接近 0.5、再取更小 radius_base（确定性 tie-break，写入预注册）。
- 记录：`calibration/calibration_report.json` / `calibration_report.csv`（每格/每任务 success、feasible_count、first_feasible、best_feasible_value、best_objective_raw、min_violation_sum、n_null、wall_s）与 `calibration_cells.csv`（每 seed 的 success/hit、pooled 值、analytic 与经验体积分数）；失败网格如实保留。
- 证据备份：`probe_v2_radius.json`（EXT/p4-m5m6/a6/）记录 pilot + 正式校准的每 seed success/hit/feasible 数与 pooled 值，供复审复算。
- 验收软指标：普通 BO 成功率 20%–80% 为难度调试目标，不是统计验收硬指标；达不到则按 §10-R1 处理（换线性约束变体 v2a 或保留 INCONCLUSIVE），不得改测试集。

**1.3 冻结与一次性开测试集**
- 冻结产物 `frozen_family.json`：family_config 全字段、参数分布、radius 映射、context 耦合、split fingerprint、code_sha、git_sha、`sha256`；**必含字段**（Lead 要求）：`family_version`（v2）、`radius_base`、`reference_solution="c"`、`gap_definition="f(u_best)-f(u*)"`、`calibration_seeds=[0,1,2]`、`pooled_success`、`feasible_volume_fraction`（固定 seed 的 MC 估计，非求解器）、以及"禁止用 meta_test/ood 调参"声明；`meta_task_split.json` 同时产出（五 split 的 task_id 列表 + 每任务 params 摘要 + split hash）。
- 冻结校验 fail-closed：frozen/preregistration 的 `sha256`、`family_fingerprint`、`radius_base`、`split_hash` 任一与当前任务/配置不符 → 拒绝构造 test/ood 并中止（测试覆盖）。
- 冻结顺序：校准报告 → 选择 radius_base（由 Lead/审阅确认）→ 写 frozen_family.json + preregistration → 校验 hash → **一次性**打开 meta_test/ood。冻结后任何公式/参数/预处理/split/终点变更都不得在测试集上重跑；需要变更必须升版本（v3）并开新 run。
- runner 增加两个阶段参数：`--stage calibration`（禁触测试集，代码断言 split 只含 train/validation）与 `--stage holdout --preregistration <path>`（校验 hash 后才构造 test/ood）；hash 不符或 frozen 文件缺失 → fail-closed 中止。
- 旧 F-QE 压力测试保留：单独配置、单独表、绝对目标不与 v2 混算。

## 2. 4 个真实可识别臂（实现路径）

目标：`M5-BO-random`、`M5-BO-pretrain-init`、`M5-BO-MAML-init`、`M5-DE` 四个**可审计不同代码路径**的臂；BO 采集策略保持一致，只允许初始化路径不同。

| 臂 | 初始 8 点生成路径 | 采集/搜索 | 证据 |
|---|---|---|---|
| M5-BO-random | 共享 LHS(8)（`shared_initial_designs(task,seed)`） | `maml_opt` `ConstrainedBayesianOptimizer`+`run_search`，56 次采集 | 初始点 digest、seed |
| M5-BO-pretrain-init | 条件预训练代理（meta_train 全部 support+query 监督预训练）对同一 64 候选池打分 → `select_model_scored_initial_designs(8, diversity=64)` | 同 BO-random 引擎（采集不变） | 代理 artifact hash、候选池 hash、排序 top-8、rank correlation |
| M5-BO-MAML-init | MAML 元训练代理（meta_train episode 外循环）对同一 64 候选池零样本打分排序 → 选 8 | 同 BO-random 引擎 | 同上 + meta seed |
| M5-DE | LHS(8) 初始种群（与 random 臂同 digest） | 独立 DE/rand/1/bin，8 代×8 个体=64（B=128 时 16 代） | 种群/代日志、无代理 |

- 公共受控适配器（新增模块 `m5_arms.py`）：`score_initial_designs(model_artifact, candidate_pool, target_names, task_context)` 只做预测+排序，**预测值绝不写入 BO observations**；观测只来自合成真值评价（满足公平性审计）。
- 可识别性审计：每 (task,seed,budget) 记录 code_path（函数名+模块版本）、initial_design_ids、candidate_pool_hash、model_artifact_sha256、top-8 overlap（两两 init 臂）、样本选择 rank 相关；若 pretrain/MAML-init 的初始 8 点与 BO-random 在 ≥90% 任务上完全相同，或两模型 artifact 等价 → 标 `CLONE_OF_OPT-BO-rand` / `NOT_COMPARABLE` 并从推断中排除；**不得改名凑四条结果**。
- maml_opt 公开 API 不足以支撑真实差异时：只用公开 initial-design 接口 + 受控 adapter（不改采集策略）；仍达不到则如实标注并排除，不新增第三方依赖。
- 与旧 M5 命名隔离：旧 5 臂（含两个 clone）保留用于历史对照，但正式 M5 结论只引用 4 个可识别臂。

## 3. 等预算 B=64 与 B=128

- 分层预算轴 `{64, 128}`；每 (task, seed, arm, budget) 恰好消耗 `budget` 次合成解析评价；BO 臂 = 8 初始 + 56/120 采集；DE = 64/128。
- 同任务、同 split、同约束定义、同 seeds、同初始候选池（init 臂 64 候选池 digest 相同）、同 null/失败处理；失败评价保留 null 计入 budget，不重试、不填充、不惩罚值。
- 审计记录：`initial_eval_count=8`、`proxy_scoring_cost{candidates, predictions, wall_s}`（不计入 true budget，单列）、`cache_requested/billable`、重复设计、`first_feasible_eval_index`（1-based，未出现为 null）。
- 缓存：每臂独立 per-(task,design) 缓存（不跨臂共享，避免交叉臂泄漏）；命中不计 billable 但记 requested；summary 同时报 cache_hits 与 billable。
- 公平性断言函数（写入 run_config 并测试）：同 split/同 K/同 query/同预算/同 task seeds/同 initial pool digest；任一不满足即 fail-closed。
- physical_call_count=0 双层守卫：合成 evaluator 返回 0、runner 启动/结束回读断言；任何 evaluator 报 >0 立即中止并写 status=PHYSICS_GUARD_VIOLATION。

## 4. ≥20 任务与 ≥10 seeds（正式规模）

- 任务：v2 meta_test 20 个互异 holdout + meta_test_ood 10 个（≥20 满足；OOD 单列）；meta_train 60 / meta_validation 20 仅用于校准与元训练；negative_control 10 由 meta_train 派生、不得进主终点。
- 优化 seeds：`{0,1,...,9}`（10 个）；元训练 seeds：`{0,1,2}`（≥3），每个 seed 训练独立 MAML/pretrain artifact。
- 组合与成本：BO-random / DE 与元训练 seed 无关，按 (task, opt_seed) 各 1 次；pretrain-init / MAML-init 按 (meta_seed, task, opt_seed) 各 1 次。B=64 与 B=128 两档分别跑。预算估算（单核 4 torch 线程）：BO 类 run 约 3–8s，DE <0.1s，全量预计 3–6h；采用 pilot→formal 分阶段，先 B=64 后 B=128，时间不足时 B=128 缩减为 meta_test 20 任务并明确声明。
- 聚合：任务层级为主（seed 在任务内聚合），≥10 seeds 提供 seed 离散度（中位数/分位数/IQR）作为次级指标；任务间 bootstrap。
- 每个正式 run 产出独立 `run_id`、run_config、meta_task_split、training_history、adaptation_results、optimization_history、metrics、summary、data_manifest、figures 数据；证据/日志备份 EXT/p4-m5m6/a6/。

## 5. M6 三臂与 K 值

- 三臂：R（随机初始化从头训练）、P（普通预训练+微调，S_adapt=50）、M（MAML 一阶）。三臂共享同一 episode（同 task/K/support/query/seed），query 只在评估函数内使用一次。
- K ∈ {0,1,5,10,20}（20 视预算；不足则前置声明未覆盖，不得省略后假装完整）；每 (arm, K, task, seed, meta_seed) 输出 adaptation_results 行：query RMSE/MAE（原始+按任务 support 目标尺度标准化）、R²、max_abs_err、wall_s、内循环 loss 首末/斜率、参数更新范数（梯度稳定性）、status。
- 任务族：v2 同分布新任务、参数外推 OOD、新函数族（F-LIN/F-MF，可含 F-NC 作为诊断）；不同族尺度用同一标准化差异并保留原始值；每族 ≥10 任务，OOD ≥10。
- 元训练 seeds {0,1,2}：报告三臂 × 三 seeds 的离散度；若计算受限未达 ≥3，必须在结论明示。
- 负控制：label-shuffle 任务上 MAML 优势应回落（预训练水平）；否则查泄漏并重跑，不得静默通过。
- 三个独立结论层级分别报告：(1) MAML 快速适应误差优势；(2) BO 样本效率/约束优化价值；(3) OOD 泛化。禁止因 K=5 RMSE 较低自动宣布 BO 更优，反之亦然。

## 6. OOD 调查（针对上轮 ood_degraded_vs_meta_test=false）

- 上轮事实：OOD 相对 meta_test 未退化。本阶段把它当**研究对象**而非成功证据，预注册 H1–H5：
  - H1 难度混杂：OOD 任务本身更易（标签方差、曲率、可行率、K=0 零样本误差、random 臂误差更低）；
  - H2 context 泄漏/错位：context 是否进特征、OOD context 平移是否被 proxy 过拟合、support/query 或 task 身份是否重叠；
  - H3 任务生成：OOD 参数构造、r 缩放、context 中心平移是否造成分布优势；
  - H4 抽样/基准：query seed、任务抽样权重、样本量；
  - H5 评估尺度：标准化与任务聚合方式影响。
- 诊断产物：每 OOD 任务的 paired delta（vs 匹配难度的 meta_test 任务）+ 难度协变量（σ_y、曲率代理、参考可行率、K=0 误差）+ 分层/回归式难度校正表；OOD 与 meta_test 的 task_id/context 分布表。
- 结论规则：仅当难度混杂被排除（或校正后差异稳健）才可称"泛化稳健"；若 OOD 更易，如实报告难度差异与"不退化≠泛化成功"；发现泄漏则修复生成并升版本重跑，**不得用 meta_test/ood 调参**。
- meta_test 任务不参与模型选择/难度调节；support/query 与 task 身份均互斥并逐 run 断言。

## 8. 终点与统计

- 预注册文件（冻结前写）：`preregistration.json` + 中文 `preregistration.md`，含主/次终点、臂、预算、任务、seed、统计模型、多重比较范围、null 规则、停止规则、sha256；打开 holdout 前由 Lead 确认。
- M5 主终点：`best_feasible_value`、`gap_to_reference`、`first_feasible_evaluation_index`、`feasible_hit_rate`；预算轴画最优可行目标曲线。`best_objective_raw`/`min_constraint_violation_sum` 仅预注册 fallback，**不得**以非可行 raw objective 宣称更优。
- M6 主终点：query RMSE/MAE（原始+标准化）；次终点：wall time、梯度稳定性、负控制差异、OOD 退化量。
- 统计单位：任务层级；seed 任务内先聚合（中位数/均值），配对差在 (task, seed, budget) 内计算后再跨任务聚合；bootstrap 10,000 次 95% CI；Wilcoxon signed-rank；效应量（配对 Cohen's d / rank-biserial）；跨任务任务族分层报告。
- 多重比较：6 个臂对 × 2 预算 × 4 主终点（M5）与 3 臂对 × K 轴（M6），按终点族 Holm-Bonferroni 校正；同时报告未校正 p 与 CI，明确探索性分析边界。
- null 规则：不可行/失败保留 null，分母含全部 run，披露未达可行比例；主终点不做插补；仅作敏感性分析（null 视为最差/最好）且标注非主结论。
- 样本不足/非null比例过低（如 <70% 任务有可行值）→ 结论 `INCONCLUSIVE` 并给原因，不补画曲线；允许可信负结果交付。
- 元训练 seed 离散度、多个独立 run 的可复算性单列。
