## 3. A线｜任务条件化 MAML 因果消融和改进

### A0：现有44标签零物理实际训练（探索性、必做，不是再写计划）

修正算法名称并实现完整2×2对照；随机初始化另列。
| 模型 | 设计特征 | 任务特征 | 训练目标 |
|---|---|---|---|
| POOLED_PRETRAIN_12D | 同一12D合同 | 无 | 联合监督MSE，无元外循环 |
| COND_SUPERVISED_16D | 同一12D合同 | Mach/q/CL_ref/h | 联合监督MSE，无元外循环 |
| FOMAML_12D | 同一12D合同 | 无 | support内更新→query外更新 |
| COND_FOMAML_16D | 同一12D合同 | 同四特征 | support内更新→query外更新 |
| RANDOM_INIT | 同合同，必要时增16D版本 | 按相应输入 | 不预训练 |

四个上下文是已知物理条件，不是设计变量。CL_ref=L_ref/(q*S_ref_baseline)，真实每设计升力仍使用对应Sref。固定高度/升力时上下文互相关，不能把4特征解释为4个独立物理自由度。任务条件16输入不等于16D优化。用训练任务拟合全部normalizer；任务特征使用已冻结物理尺度。若训练集某维不变，报告并固定或按工程边界归一化，不用极小样本标准差放大测试点。

- 首先实际复跑既有44条、种子7/19/43、K=0/1/3（K=0作为零适应诊断）。同K下每种子相同support集合、不同seed/重复组合可预注册而不以test结果挑选；query不得用于适应。K=5仍NOT_ELIGIBLE，除非预先增加5个独立支持几何及多个独立query。
- 同输入比较元学习与普通监督时采用相同网络、任务均衡规则/标签暴露、训练/验证集；记录训练更新次数、梯度/样本处理数与CPU/GPU墙钟，不假称相同步数=相同成本。所有训练臂统一验证K与checkpoint选择，禁止普通预训练挑best而MAML强制last；使用相同有限超参搜索预算（例如验证内学习率0.005/0.01/0.05，适应步数1/3/5的预注册有限网格或等量子集），先在train/val选定再锁定。所有种子和负结果保留；仅train/val用于选择/排序设计，旧M240/M260只复现。允许MAML输给条件普通预训练，不以赢为下一阶段门槛。
- 主要机制指标：COND_FOMAML_16D - COND_SUPERVISED_16D 的同任务同K同seed配对MAE/RMSE差，和无条件两个臂的差；同时报告上下文效应、排序Spearman、top-k真实Di与已评候选池内的选择后悔值、K=0/1/3适应增益、训练/适应成本。单query不算排序证据。
